# Developer Scripts

These are standalone utility scripts for local development and debugging. Run them from the project root (`python scripts/<script>.py`).

| Script | Purpose |
|--------|---------|
| `seed_db.py` | Populates the database with sample data for local development |
| `check_users.py` | Prints all users in the database for debugging |
| `init_chats.py` | Creates initial chat channels |
| `verify_allocation_flow.py` | Integration smoke test for the referee allocation flow |
| `verify_captain_flow.py` | Integration smoke test for the captain team-management flow |
| `verify_scheduling.py` | Integration smoke test for fixture scheduling |
| `verify_scoring.py` | Integration smoke test for score submission and standings update |
